Detailed Description

Event awaitable that can be awaited by coroutines, resuming them once triggered.

This is the read part of a onedirectional oneshot communication channel. To create the pair, use mrs_lib::coro::make_event.

Wait for the event to trigger / cancel.

Result of this function must be awaited.

Note
Every event can only be awaited once. To help enforce that behavior, this method is rvalue qualified. As a result, this must be awaited as rvalue (eg. using co_await std::move(awaiter).wait()).
